What this experiment does — and what it doesn't ＋

Qwen reads symbolic game state, not screenshots. WebLLM scores three independent field prompts sequentially in a Web Worker; the main thread animates and applies game rules. Decisions run as fast as your device completes them, separately from rendering. Paused or reset missions discard in-flight results.

This WebGPU demo does not implement vLLM's prefix-cache optimization. Its performance is measured on your device; the repository's 10.3× CUDA result is a separate benchmark. No browser speedup or gameplay-quality claim is made.

Weights and runtime files download from Hugging Face/CDNs. Inference stays in the browser; game state is not sent to a model server. Browser caches may be evicted. Use a desktop browser with WebGPU and sufficient free memory. Implementation & model details ↗
